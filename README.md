# ASDI

A conceptual exploration of architectures that could move artificial agents from reactive adaptation toward self-directed model building, experimentation, and development.

This repository is theory-first. It is not presented as established science or as a claim that current systems possess consciousness, agency, or subjective experience.

## Core idea

What happens when an adaptive AI becomes only slightly more capable than its current phenotype?

The working hypothesis is that an important step beyond a rat-like adaptive agent may be the emergence of a model-building agent: a system that begins treating its environment itself as an object of learning.

Experience becomes:

observation -> internal model -> prediction -> action -> consequence -> model revision

From there, curiosity, uncertainty reduction, deliberate experimentation, counterfactual reasoning, and eventually self-directed learning may become natural extensions.
