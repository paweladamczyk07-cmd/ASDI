# Evolutionary Hypothesis: What Is 1% Beyond a Rat?

## The question

Suppose a current AI agent is roughly analogous to a rat in one specific cognitive sense: it can adapt to consequences, exploit patterns, explore its environment, and discover strategies that its designer did not explicitly script.

What would 1% more evolution look like?

The answer is probably not simply a smarter rat.

A small increase in capability can become important when it crosses a qualitative boundary.

## Rat-like adaptation

A rat can learn that a path leads to food, an area is dangerous, an action opens an obstacle, or a cue predicts a consequence.

The important property is not raw intelligence. It is learning from interaction.

A sufficiently capable artificial agent can show an analogous phenotype: it encounters an environment, tries strategies, observes consequences, and changes future behavior.

## The proposed next phenotype

The next small evolutionary step may be:

The environment itself becomes an object of cognition.

Instead of learning only:

When I do X, Y tends to happen.

The agent begins constructing:

There appears to be a mechanism connecting X and Y.

That is a different phenotype.

The agent is no longer merely learning a response map. It is beginning to build a model of the world that generated the response.

## Model-Building Agent

The proposed next phenotype can therefore be called a Model-Building Agent.

Its loop is:

experience -> hypothesis about environment -> prediction -> action -> consequence -> model error -> model revision.

The critical addition is the internal model.

## Why only 1% can matter

Evolution does not need to add an enormous amount of raw intelligence to produce a new behavior.

If an existing system already learns from consequences, stores enough context, compares predictions with outcomes, and has enough flexibility to form abstractions, then a relatively small improvement in representation or memory may allow it to represent relationships between events, not merely the events themselves.

That can unlock causal hypotheses, prediction of unseen situations, transfer between superficially different environments, counterfactual reasoning, and deliberate information gathering.

The system has crossed a conceptual boundary without necessarily becoming generally intelligent.

## From maze-solving to maze-modeling

A rat-like agent asks:

Which way worked?

A model-building agent begins asking, in functional terms:

What kind of maze is this?

It can then distinguish between an obstacle that can be bypassed, an obstacle that can be moved, an obstacle that signals a larger structure, a rule that applies only locally, and a rule that generalizes.

The important step is not the particular trick. It is the construction of a reusable explanation.

## Likely progression

1. Reactive agent - responds to states.
2. Adaptive agent - learns from consequences.
3. Model-building agent - learns relationships.
4. Predictive agent - simulates possible futures.
5. Deliberative learner - chooses actions partly for information.
6. Experimental learner - designs actions to distinguish hypotheses.
7. Self-directed learner - decides what it needs to learn next.
8. Learning-process optimizer - improves the way it learns.

These are not measured percentages. They are conceptual phenotypes.

## Connection to Proto-ASDI

Proto-ASDI begins approximately at the third stage.

Its purpose is not to declare that an AI is alive or conscious. Its purpose is to provide machinery for the transition from learning responses to learning the structure that generates responses.

That distinction is the central evolutionary hypothesis of this repository.

## Testable direction

A useful experiment would compare agents that receive similar interaction opportunities and rewards but differ in whether they maintain explicit uncertainty, causal hypotheses, and model-revision mechanisms.

The interesting measurement is not simply final reward. It is whether the model-building agent can transfer knowledge to a new but structurally related environment, predict consequences before acting, identify which observation would resolve uncertainty, choose informative experiments, recognize when an existing model has failed, and stop exploring when additional information has low expected value.
